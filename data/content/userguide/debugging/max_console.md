# Max Console
The **Max Console** displays printed text messages including status information, error messages, and warnings. If your patcher isn't working the way you expect, one of the first things you should do is check the Max Console to see if any error messages appear here. You can write to the Max console directly using the [print](https://docs.cycling74.com/reference/print/ "print") object, or in **Debug Mode** by using a _Print Watchpoint_ on a patchcord (see [Debugging and Probing](https://docs.cycling74.com/userguide/debugging_and_probing/)).
## Showing the Max Console
### Max console sidebar
Click on the Max Console button on the right-hand toolbar to open the Max Console in the sidebar. To close the sidebar, click on the Close button, or click on the Max Console button.
![](https://docs.cycling74.com/images/a483ba329b3d02a0d306ce631c1b6ba8_267.webp)
The Max Console sidebar provides all of the functions of the Max Console window. Additionally, you can limit the messages viewed in the Max Console sidebar by clicking on the _Messages for This Patcher Only_ icon at the top of the sidebar.
![](https://docs.cycling74.com/images/7f346dd53cf83964a02fd9b4a68e5dfd_325.webp)
### Dedicated window
Open the _Window_ menu and choose `Max Console`. This will display the console in its own window. The Max application keeps track of whether or not the Max Console is visible when you quit the program, and will hide or show the window at its last size and position when you relaunch Max based on its state when you last used Max.
## Using the Max Console
### Clearing the console
Clear the Max Console by clicking the _Clear All_ button in the bottom toolbar.
![](https://docs.cycling74.com/images/e0d1506ba08306728a0f2985057a0285_382.webp)
You can also select the lines that you'd like to delete, and choose _Delete_ or _Cut_ from the _Edit_ menu.
### Viewing message time
The _Show Message Time_ button will display the time since each message was generated.
![](https://docs.cycling74.com/images/799652f2454dc2a2185ba5f0fa09484d_381.webp)
### Finding the object that generated a message
If a row of the Max Console displays the name of an object, hover over the row and a green tinge will appear over the object. Double-click on the row to cause the object that generated the error to be scrolled into view and brought to the front. You can also click the _Show Object_ button in the bottom toolbar.
![](https://docs.cycling74.com/images/3f1698852e97129190aeef2cd5276442_595.webp)
You can also use the [Max Console Contextual Menu](https://docs.cycling74.com/userguide/max_console/#the-max-console-contextual-menu) to find the object that generated a message.
### Copying text
To copy text from the Max Console, select the lines you want to copy, then choose _Copy_ from the _Edit_ menu.
### Filtering the contents of the Max Console
Suppose the Max Console contains the following: 
![](https://docs.cycling74.com/images/e7c5144c9d610eb49b5dbac689b83ef0_305.webp)
Enter any text into the filter field to display only messages that contains that text. 
![](https://docs.cycling74.com/images/58696b8f1b8ac64aa16ae8b166c2b65f_304.webp)
Click the "+" button to the right of the filter field to add search criteria. This will let you filter for messages from a particular object, patcher, or class of objects. You can also command-click or right-click on a console line to display the contextual menu, then select "Filter By This Object" to show only messages generated by that single object.
![](https://docs.cycling74.com/images/d86ca01a740aab96e3f3320a20fcd4f3_310.webp)
You can use regular expressions in the search field as well by beginning and ending your search query with a `/` character. 
![](https://docs.cycling74.com/images/d25d8f73bbcefaf2f7cd66425c8d3856_412.webp)
Finally, the _Show Only Errors_ button button in the bottom toolbar will hide all messages except for errors.
### The REPL
The [REPL](https://docs.cycling74.com/userguide/repl/) (Read-Evaluate-Print-Loop) at the bottom of the Max Console lets you interact with the current Max patcher using text.
![](https://docs.cycling74.com/images/100b61de185bc76395fbfc28f3360017_212.webp)
Using the REPL, you can:
  * Send messages to Max objects in your patcher
  * Evaluate JavaScript expressions
  * Control the Max environment with text-based commands
  * Access the documentation


Check out the [REPL documentation](https://docs.cycling74.com/userguide/repl/) for more information.
## Adjusting the Font and Size
To adjust the font and size, bring the [dedicated Max console window](https://docs.cycling74.com/userguide/max_console/#dedicated-window) to the front, then choose _Show Fonts_ from the _Object_. Your chosen font and size will be saved for the next time you launch Max.
## Color Coding and Errors
Rows of the Max Console are color coded.
  * **gray/white** : status information or messagess sent to a [print](https://docs.cycling74.com/reference/print/ "print") object
  * **yellow** : warnings
  * **red** : error messages
  * **blue** : internal errors (bugs in Max itself)


You can find a listing of common error messages [here](https://docs.cycling74.com/userguide/error_messages/).
On the patcher toolbar, the Max Console button will display a badge if there are any errors or printed messages to be displayed. The badge can be cleared by setting focus to the Max Console window.
![](https://docs.cycling74.com/images/683ad48e7dc8e14b0edb0bd627870b5b_231.webp)
## The Max Console Contextual Menu
Command-click or right-click on a Max Console message to display the contextual menu. There are several options for using the messages as well as managing the Max Console contents.
![](https://docs.cycling74.com/images/ceab019db3b3dded2ad0b5f5c0353f3a_334.webp)
  * _Show This Object_ will bring the object into view and apply a green tinge over the object.
  * _Select This Object_ will select the object that generated the message.
  * _Filter By This Object_ will filter the contents of the Max Console to show only the current object's messages. To remove the filter, click the Remove Criteria button at the top of the window.
  * _Copy All Output_ By This Object will copy the text of all of an object's messages to the clipboard. This can be useful for capturing data or documenting error conditions.
  * _Delete All Output_ By This Object will remove all messages generated by the object that generated the selected message. Once deleted, the text cannot be retrieved.


## Console-related Objects
### The [print](https://docs.cycling74.com/reference/print/ "print") and [error](https://docs.cycling74.com/reference/error/ "error") Objects
Use the [print](https://docs.cycling74.com/reference/print/ "print") object to log a message to the Max console. You can also use the [error](https://docs.cycling74.com/reference/error/ "error") object in the same way, except any messages sent to the [error](https://docs.cycling74.com/reference/error/ "error") object will have special "error" formatting.
### The [console](https://docs.cycling74.com/reference/console/ "console") Object
The [console](https://docs.cycling74.com/reference/console/ "console") object lets you receive messages that would print to the Max console directly in your patcher. The [console](https://docs.cycling74.com/reference/console/ "console") object can receive warnings, errors, or just general messages. You can also use the `textfilter` message to set a filter for the [console](https://docs.cycling74.com/reference/console/ "console") object specifically, the same as the text filter in the console itself. See the [console object helpfile](c74max://patcher/console.maxhelp) or the [console](https://docs.cycling74.com/reference/console/ "console") object reference for more information.
