# Format Palette
The **format palette** is a specialized interface for customizing the look of your patcher. It lets you change object and patch cord colors, font size and style, [syntax highlighting](https://docs.cycling74.com/userguide/syntax_coloring/) colors, and other attributes related to appearance. The format palette can configure specific objects, or it can apply patcher-level formatting, affecting all objects in the current patcher.
## Opening the Format Palette
Open the format palette by clicking the _Format_ icon in the [top toolbar](https://docs.cycling74.com/userguide/patcher_window/#top-toolbar).
![](https://docs.cycling74.com/images/f45504d4e7b3f498c52d13e0541c66f8_908.webp) Click the Format icon to expose the format palette.
Along the top of the format palette, you'll see all of the configuration options for the current selection. Hover over a configuration option to see the name of the option.
![](https://docs.cycling74.com/images/8939a6a50813a7c98b3c11426606aae9_238.webp) Hover over a format option to see its name.
## Patcher-level Formatting
With no objects or patch cords selected, the format palette shows patcher-level formatting options. Any change you make here will apply to all objects in the current patcher, unless those objects override those changes with individual settings.
![](https://docs.cycling74.com/images/2c35e76679b5f625436c68f345b16f63_302.webp) Patcher-level formatting for the Object Accent Color changes the style of all objects in the patcher, except for those with individual settings.
You can hide patcher-level formatting options by clicking the Hide Patcher-Level Format icon in the top-left.
Patcher-level formatting can be used to change the [syntax highlighting](https://docs.cycling74.com/userguide/syntax_coloring/) for the current patcher, with options to change the color for object names, arguments, attributes, and attribute arguments.
If a configuration option is missing from the format palette, you may need to expand the size of the window to make room for more options.
## Styles
The format palette can be used to apply, create, and modify [styles](https://docs.cycling74.com/userguide/styles/). See the [Styles](https://docs.cycling74.com/userguide/styles/) guide for an in-depth discussion.
