# MC Event Objects
  * **[multirange](https://docs.cycling74.com/reference/multirange/ "multirange")** - Two-dimensional function editor used to create definitions for [mc.evolve~](https://docs.cycling74.com/reference/mc.evolve~ "mc.evolve~") and [mc.gradient~](https://docs.cycling74.com/reference/mc.gradient~ "mc.gradient~")
  * **[mc.gen](https://docs.cycling74.com/reference/mc.gen "mc.gen")** - Host multiple Gen patches for event processing
  * **[mc.target](https://docs.cycling74.com/reference/mc.target "mc.target")** - Format messages for individual voice targets
  * **[mc.targetlist](https://docs.cycling74.com/reference/mc.targetlist "mc.targetlist")** - Format messages for all defined voice targets
  * **[mc.line](https://docs.cycling74.com/reference/mc.line "mc.line")** - Produce multiple linear ramps with a voice identifier
  * **[mc.cell](https://docs.cycling74.com/reference/mc.cell "mc.cell")** - Format [jit.cellblock](https://docs.cycling74.com/reference/jit.cellblock "jit.cellblock") selections into targeted event messages
  * **[mc.makelist](https://docs.cycling74.com/reference/mc.makelist "mc.makelist")** - Create lists using a target voice index
  * **[mc.route](https://docs.cycling74.com/reference/mc.route "mc.route")** - Route messages based on a target voice index
  * **[mc.function](https://docs.cycling74.com/reference/mc.function "mc.function")** - A version of the [function](https://docs.cycling74.com/reference/function/ "function") object containing multiple functions
  * **mc.input** - A version of the [mc.target](https://docs.cycling74.com/reference/mc.target "mc.target") object with multiple inlets
