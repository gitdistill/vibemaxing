# type DrawingPrimitiveType
Primitive type to use for drawing shapes. See [Sketch.shapeprim()](https://docs.cycling74.com/apiref/js/sketch/#shapeprim "Sketch.shapeprim\(\)").
```
export declare type DrawingPrimitiveType =
	"lines"
	| "line_loop"
	| "line_strip"
	| "points"
	| "polygon"
	| "quads"
	| "quad_grid"
	| "quad_strip"
	| "triangles"
	| "tri_grid"
	| "tri_fan"
	| "tri_strip";

```
